# Build your own AI brain

The maintained starting point is [the staged setup](setup.md), invoked with [the setup prompt](../prompts/setup.md). The [README](../README.md) includes copyable setup and schedule prompts. Maintenance and scheduling are in [maintenance.md](maintenance.md).

A standalone Markdown handoff can be generated with `python scripts/build_standalone.py --output /absolute/path/Build-Your-Own-AI-Brain.md`. It embeds the maintained templates, docs, helpers and tests with checksums; it does not require the author's private repository. Rebuild it from source rather than editing a second copy.
